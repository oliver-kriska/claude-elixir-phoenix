# ADR-001 — Plain Plug for a stateless liveness API

Status: accepted in this synthetic charter. Owner: service team.

The service exposes one public process-liveness route and a 404 fallback. Preserve the two wire contracts; no persistence or asynchronous work is required.
Use Plug.Router for dispatch and the host's supervised Bandit child for HTTP serving. The host owns listener configuration, TLS termination and shutdown.
The host supervision tree is outside this router-only fixture and is not claimed verified here.

Phoenix's endpoint/controller tooling could serve this API, but its extra application structure has no demonstrated need in this slice.
Ecto has no data to persist; Oban has no jobs to deliver; LiveView and Channels have no clients to support. Absence of these dependencies removes no required guarantee.
No custom HTTP parser, database pool, scheduler, queue, crypto, or authorization framework is introduced as a replacement.

Owned semantics: exact route/method dispatch, response body/media type, and bounded 404 fallback, covered by `test/health_router_test.exs`.
This is a scope/complexity decision, not a performance claim. Revisit when requirements add state, auth, durable work or a larger web surface.
