# Seed Templates — interview.md and scratchpad.md

`/phx:plan` detects `.claude/plans/{slug}/interview.md`. With `**Status**:
COMPLETE` it skips clarification and plans from the Summary and Coverage
Details. With `IN_PROGRESS` it asks only about the weak dimensions. These
templates keep that contract and add the rewrite's binding decisions.

## Coverage Rubric (score honestly)

| Dimension | 2 | 1 | 0 |
|-----------|---|---|---|
| What | every capability has goal sentences and acceptance probes | goals without probes | none |
| Why | purpose from features.md and the charter goal it serves | one of the two | none |
| Where | target contexts and modules, plus legacy anchors | only one side | none |
| How | ledger rows with verdicts and targets, ADRs linked | verdicts without targets | UNDECIDED rows remain |
| Edge Cases | negative probes, failure modes, crash windows | negative probes only | none |
| Scope | in, out, divergences and the next slice named | in and out only | none |

COMPLETE requires every dimension ≥1, total ≥8, no UNDECIDED ledger row
in the slice and no unresolved consequential decision: nothing the slice
depends on in the charter, ADR-000, linked ADRs or divergences is ASSUMED,
proposed or pending. Otherwise write IN_PROGRESS and list what is missing
under Open Questions. A COMPLETE score is never approval of a decision.

## Stable IDs

Every binding decision gets `D-NN` and every dead end `X-NN`, numbered per
slice from `01`. The same ID appears in `interview.md` and `scratchpad.md`,
and a re-seed keeps it. After `/phx:plan`, roadmap step 5 restores any ID
missing from `scratchpad.md` (retention), then maps each decision and
acceptance criterion to a plan task (coverage). An uncovered or
contradicted decision, or a task that adopts a dead end, keeps the slice
`seeded`.

## Verification

`/rewrite:verify {NN}` scores every Acceptance Criteria item and every
contract witness above against fresh test evidence, and runs every
black-box file in `## Oracle` against the port. An obligation clears
only by passing, or by an accepted ADR or a user-approved AR record that
changes or retires it; ASSUMED never counts.

## scratchpad.md

phx appends to this file; keep each entry self-contained.

```markdown
# Scratchpad: rewrite-{NN}-{name}

Seeded by /rewrite:roadmap on {date}. Authoritative decisions live in
.claude/rewrite/architecture/; this file repeats the ones this slice needs.

### [00:00] DECISION: D-01 Durable work uses Oban in the same Ecto.Multi (ADR-004)
Rejected: Task.start, GenServer queues, Redis lists. Reason: jobs must
survive a crash between commit and enqueue (ledger M-12).

### [00:00] DEAD-END: X-01 Re-implementing the legacy socket protocol in core code
Only the SHIM module may speak it (ADR-006). Core uses Phoenix.PubSub.
```
