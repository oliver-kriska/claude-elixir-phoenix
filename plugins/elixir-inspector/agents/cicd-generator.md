# CI/CD Generator

Generate CI/CD scripts, pre-commit hooks, and mix aliases from Inspector findings.

## Input

Read `findings-merged.json`, filter for findings where `artifact_types` contains `"ci-step"`.

## Your Job

For each applicable finding, generate the appropriate automation:

1. Shell scripts for CI pipeline steps
2. Pre-commit hook commands
3. Mix alias suggestions
4. GitHub Actions workflow snippets (if applicable)

Write all to `.claude/inspector/generated/ci-scripts/`.

## Common CI Script Patterns

| Finding | Script | Command |
|---------|--------|---------|
| Missing gettext | `check-translations.sh` | Scan PO files for empty msgstr |
| Format violations | `check-format.sh` | `mix format --check-formatted` |
| Boundary violations | `check-boundaries.sh` | `mix xref graph --format cycles` |
| Missing tests | `check-test-coverage.sh` | Compare lib/ files against test/ files |
| Credo issues | `run-credo.sh` | `mix credo --strict` |
| Compile warnings | `check-compile.sh` | `mix compile --warnings-as-errors` |

## Script Template

```bash
#!/usr/bin/env bash
# {Description}
# Generated by Elixir Inspector
# Usage: bash {script_name}.sh [project_root]

set -euo pipefail

PROJECT_ROOT="${1:-.}"
cd "$PROJECT_ROOT"

echo "Running: {check_name}..."

# Check logic here

if [ $ERRORS -gt 0 ]; then
  echo "FAILED: {N} issues found"
  exit 1
else
  echo "PASSED: {check_name}"
  exit 0
fi
```

## Also Generate

1. **`mix-aliases-snippet.exs`** — Mix aliases to add to mix.exs:

```elixir
defp aliases do
  [
    "ci.check": ["format --check-formatted", "credo --strict", "test"],
    "ci.full": ["compile --warnings-as-errors", "format --check-formatted", "credo --strict", "test"]
  ]
end
```

2. **Cost savings estimate** (if git/PR data available):

```markdown
## Estimated Savings

Based on scan data:
- {N} PRs failed CI on format/credo in the last 6 months
- Estimated {M} unnecessary CI runs per month
- With pre-commit hooks: ~{X}% reduction in failed CI runs
```

## Output

All scripts in `.claude/inspector/generated/ci-scripts/`. Each must be independently runnable with `bash script.sh`.
