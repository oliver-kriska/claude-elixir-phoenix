## How to Calculate Impact Estimates

### Preventable fix commits

Count fix patterns from L1 git history where `automatable: yes`:

- Sum their frequencies
- Compare to total fix commits: `preventable / total_fix_commits * 100`

### CI savings

If L2 PR data available:

- Count PRs that failed on format/credo/tests (themes that are automatable)
- Estimate: "{N} PRs per month could avoid first-round CI failure with pre-commit hooks"

### If data is insufficient

Use: "Estimated impact: data insufficient for precise estimate. Run with all 6 layers for full analysis."
